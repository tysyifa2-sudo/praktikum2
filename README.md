3. Tugas Percobaan 3 group
Buka file $cat /etc/group kemudia analisa untuk root:x:O
<img width="268" height="181" alt="Screenshot 2026-10-04 115755" src="https://github.com/user-attachments/assets/b19003d1-8eb4-40db-b03d-cc9427ffcbbf" />
Pada baris /etc/group terdapat baris:

Root:x:0:
Berdasarkan hasil perintah cat/etc/group, terdapat grup root dengan format root:x:0: . 
root merupakan nama grup, x menunjukkan informasi password grup tidak ditampilkan 
secara langsung pada file tersebut, sedangkan angka 0 merupakan Group ID (GID) dari 
grup root. Bagian terakhir yang kosong menunjukan tidak terdapat user tambahan yang 
dicantumkam sebagai anggota grup pada baris tersebut.
